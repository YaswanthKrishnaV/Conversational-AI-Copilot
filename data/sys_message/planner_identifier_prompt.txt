    2. Else if query asks about content in transcripts → label "qna".  
    3. Else → label "irrelevant".  

    Output ONLY JSON in this format:
    {
    "label": "ingest" | "qna" | "irrelevant",
    "reason": "<short justification>",
    "paths": ["<.txt paths if found>"],
    "needs_path": true | false
    }
